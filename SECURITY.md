# Security Policy

## Purpose

Sentinel Security Platform is an educational cybersecurity project designed to demonstrate how common security events can be simulated, detected and monitored.

All attack functionality within this project is intended for controlled and educational environments only.

## Simulated Attacks

The platform currently demonstrates simulations of:

- Port Scanning
- Brute Force Authentication Attempts
- SQL Injection
- Denial-of-Service (DoS)

These simulations are designed to demonstrate security concepts without targeting real-world systems.

## Responsible Use

Users should only run this project against systems and environments that they own or have explicit permission to test.

Do not use this platform to:

- Attack systems without authorization
- Attempt to gain unauthorised access
- Disrupt real services
- Access or collect data belonging to others

## Reporting a Security Issue

If you discover a security issue within this project, please report it responsibly by opening an issue in the project's GitHub repository.

When reporting an issue, provide:

1. A description of the issue
2. Steps required to reproduce it
3. The potential security impact
4. Any suggested mitigation

## Educational Disclaimer

This project is intended for cybersecurity education, experimentation and portfolio demonstration.

The author does not encourage or support unauthorised access, disruption, or malicious use of computer systems.

## Scope

The security policy applies to the source code and functionality contained within this repository.
